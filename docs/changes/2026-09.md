  - 동일 메시지 재시도는 방/발신자/클라이언트 UUID로 만든 기존 PK를 재사용하여 중복 저장 방지. 구버전 클라이언트 요청 호환 유지.
  - 메시지 저장과 방 수정시각 갱신을 단일 DB 트랜잭션으로 묶음. 저장 후 푸시는 응답 이후 별도 처리하며 실패를 로깅하고 저장 성공을 뒤집지 않음. 푸시 자체는 best effort이며 영속 재시도 큐는 이번 범위에 포함하지 않음.
